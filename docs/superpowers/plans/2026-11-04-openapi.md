# Contrato OpenAPI de las rutas REST existentes

Objetivo: completar el pendiente OpenAPI de BOOT-006 con un documento JSON
descargable en `/api/v1/openapi.json` y un artefacto reproducible versionable en
`docs/openapi.json`. Se mantiene la autenticación y el comportamiento actuales.

Se usa OpenAPI 3.1 y JSON Schema de los contratos Zod instalados; no se incorporan
dependencias ni una pantalla Swagger con ejecución de comandos. La definición de
rutas expande los comandos REST existentes y un test compara el inventario con
los controllers Nest. Los cuerpos se generan del mismo esquema de runtime;
normalización/refinamientos no representables se explican expresamente. Se
documentan cookie/CSRF/Origin, bearer API, permisos, idempotencia, paginación,
respuestas y errores. MCP y Socket.IO conservan sus protocolos separados.

Referencias: [OpenAPI 3.1.1](https://spec.openapis.org/oas/v3.1.1.html) y conversión
[JSON Schema de Zod](https://zod.dev/json-schema). La validación de negocio sigue
en servidor; OpenAPI no reemplaza claims, versiones ni permisos vigentes.
