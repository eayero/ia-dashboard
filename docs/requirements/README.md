# Requisitos existentes

Fuente única de producto: [SPECIFICATION.md](../SPECIFICATION.md), FR-001…020 y
condiciones no funcionales. Leer junto con [DECISIONS.md](../DECISIONS.md): los
textos originales y sus sustituciones se conservan, sin convertir propuestas en
decisiones. Las entidades de requisitos del producto siguen pendientes.

[TRACEABILITY.json](TRACEABILITY.json) enlaza requisitos, Q, tareas y evidencia.
Sus valoraciones parciales son índices de auditoría, no criterios nuevos ni
declaraciones globales de cumplimiento. El requisito de proceso de esta migración
procede del encargo actual y se identifica aparte de los FR del producto.
